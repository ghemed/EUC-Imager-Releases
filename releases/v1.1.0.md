## Horizon Imager 1.1.0

Built-in HTTPS, a certificate you can install from Settings, automatic refresh of old data and many list and dialog improvements.

### Downloads
* **EUC-Imager-Installer-1.1.0.exe**: Windows installer (Windows Server 2019 or later). Check it against `SHA256SUMS.txt`.
* Docker: `docker compose` with `docker/docker-compose.yml` from the repository (image `ghcr.io/ghemed/euc-imager:1.1.0`).

### Highlights
* **HTTPS built in.** nginx is gone; the app serves HTTPS itself and port 80 only redirects. Install your own certificate in *Settings, Security, Server certificate* (PEM, PFX or a signing request created on the server).
* **Upgrading a Windows install that used nginx:** run the installer over it. It keeps the certificate, removes the nginx service and opens ports 443 and 80 in Windows Firewall.
* **Automatic sync** when data is older than a configurable number of hours (default 3).
* Snapshot count on Master Images opens the snapshot window; Esc closes any dialog.
* **Push image** from Master Images lists the Instant Clone pools of the image's environment; the Push Image wizard marks the snapshot the pools already run.
* **Environment shown and remembered:** a bar under the header names the environment you are viewing, and the choice survives a page reload.
* **Task indicator** next to the Alerts bell on the Dashboard: "No tasks running", or the number of running syncs, replications and image pushes (listed on hover).
* Real status in the VM lists, resizable table columns, per-pod outdated agent check, export on every list.

Full list: [CHANGELOG.md](../CHANGELOG.md).

### Upgrade notes
* Back up the data folder (`<install folder>\instance`, or the Docker `appdata` volume) first. Database migrations run automatically.
* Docker users: the `nginx` service and the `./certs` folder are no longer used; the certificate now lives in the `appdata` volume.
